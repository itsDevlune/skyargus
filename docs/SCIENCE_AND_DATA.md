# Science and data
Actual SPHEREx DR1 dated Level 2 exposures from IRSA SIA2/IBE are central. QR3 is selectable. A merged sky cube is not used as a dated sequence. Search bounds: 100 metadata rows, 8 cutouts, one detector, 1–20 arcmin full width/height. The first 100 archive rows are a bounded sample; chronological ordering is within the returned subset, not a complete survey timeline.

IMAGE, FLAGS, VARIANCE and WCS-WAVE HDUs retain their native identity. Original files and checksums remain downloadable. IMAGE values are surface brightness, MJy/sr; no source flux is inferred from one pixel. Display images use bilinear WCS reprojection onto a TAN grid with 6.2 arcsec pixels, north up/east left; footprints and NaN are transparent. Flag images use nearest-neighbor sampling; header-provided bit definitions are decoded. Native uncertainty is retained, not incorrectly treated as reprojected quantitative variance.

Field-center visualization wavelength/bandwidth uses bilinear WCS-WAVE interpolation with alternate WCS raw-detector offsets. A real-file test compares independently against Astropy WCS-TAB (irrelevant celestial SIP removed). The initial v1 lookup omitted these offsets: its reports remain immutable and unvalidated; use processing v2 for corrected values. Visualization wavelengths are not a calibrated response product. Same detector does not imply spectral comparability.

Scientific analyses (spectrum, difference, epoch stacking, composite):
- Quick-look aperture spectrum extraction: Implemented in `science.analysis.extract_source_spectrum` using methods adapted from the official Caltech/IPAC SPHEREx Source Discovery Tool demo (`aperture_photometry.py` by Zafar Rustamkulov). Operates on un-reprojected native cutouts with local background subtraction via circular annuli, WCS-WAVE lookup with SIP disabled, pixel solid angle conversion from MJy/sr to mJy, MSKN quality bitmask tracking, and variance propagation.
- Image difference: Implemented in `science.analysis.compute_frame_difference`. Reprojects dated observations to the common target grid, reports nominal field-center WCS-WAVE display-band overlap separately from calibrated response (`not_assessed`), computes Frame B - Frame A residuals, propagates combined variance (Var B + Var A), and renders a zero-centered arcsinh preview. The UI warns that measured alignment, background, response and PSF matching are not assessed.
- Epoch stacking: Implemented in `science.analysis.compute_epoch_stack`. Rejects disjoint or unassessed nominal display bands, applies inverse-variance weighting (`weighted_stack`) across selected frames on the common celestial grid, masks out pixels flagged by bad MSKN bitmasks (SUR_ERROR, NONFUNC, MISSING_DATA, HOT, COLD), tracks per-pixel hits, and produces an arcsinh preview plus FITS with propagated VARIANCE HDU. Even overlapping display bands do not establish calibrated response comparability.
- Spectral false-colour composite: Implemented in `science.analysis.compute_spectral_composite`. Maps three distinct SPHEREx wavelength bands to Red, Green, and Blue channels using individual arcsinh contrast scaling, disclosing channel mappings, wavelengths, and dates. It is explicitly a visualization, not calibrated colour or photometry.

Manual apparent motion uses spherical offsets and a linear fit over dated marks, with a user-supplied isotropic positional error. Its numerical RA-wrap/cosine test passes. The error assumption is not a measured alignment residual; manual associations may identify different stars. No hazard, orbit, distance or discovery probability is inferred.

NEOSSat has a separate CADC adapter and raw optical native-detector mode. Only documented DATASEC is displayed. Raw counts have no overscan/dark/photometric correction. No celestial registration or sky motion is inferred. The original FITS with telemetry extensions is preserved. Different detector shapes are excluded.

Gaia overlay uses explicit gaiadr3.gaia_source, epoch J2016.0; proper motion is returned but not propagated. WISE imagery is not yet integrated. No cross-survey brightness difference is claimed as variability.
