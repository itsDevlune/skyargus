# Concrete audit
Verified mitigations: CSRF rejects tokenless writes; different sessions cannot read jobs/private reports or mutate candidates; stale annotation edits return 409; reports have no mutation endpoint; revocation invalidates read links; HTTPS exact archive-host allowlist rejects localhost/IPs/credentials/alternate ports before network; redirects are bounded and revalidated; requests cap returned bytes and timeouts; UUID artifacts never expose disk paths; templates escape notes/titles; native FITS kept apart from display JPEG/PNG math; coordinate NaN/ranges and FOV limits tested.

Known unresolved risks: per-session/global quotas are counted without transactional reservations; session creation can bypass session quotas unless edge controls are comprehensive. Full FITS decompression/HDU total allocation limits need more adversarial testing. Per-observation transient retries/backoff are unfinished. A 210s budget is checked between observations, not inside a slow download. Redis failure/restart, full disk and multi-subscriber concurrency need fault tests. Orphan files can remain after transaction rollback or a stale analysis attempt writes an artifact before its fenced result update. Catalog/source access limits need production policy review. Public archive downloads are read-only but SSRF DNS rebinding/private-resolution defenses beyond exact host allowlisting need audit.

Worker recovery now uses the monotonically increasing `Job.attempts` value as a fencing generation: queued-to-running claims are conditional, and stage/result/error writes require both the running state and matching generation. A late worker cannot overwrite a recovered attempt's job state or result. This does not yet clean artifacts written by a stale attempt.

Scientific: display reprojection has no propagated variance; local response comparability, measured alignment, calibrated PSF subtraction, absolute source flux and proper-motion catalog propagation are not verified. v1 wavelength mapping was incorrect; processing v2 corrects raw lookup offsets and old report snapshots are not silently rewritten. No validated discovery claim is presented.
