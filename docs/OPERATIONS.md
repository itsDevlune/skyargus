# Operations and recovery
Job state is persisted. Local worker: python manage.py workjobs. Production: Celery argus.celery:app with Redis, concurrency 1. Durable Dispatch intent is created transactionally; publisher errors leave intent pending. Reconciler --publish revisits jobs and limits repeated publication to one minute. Duplicate normal delivery sees nonqueued state and exits. --recover requeues workers stale for 10 minutes; fencing against a still-active late worker is unfinished. Never run two local SQLite workers.

Cancellation changes queued directly to cancelled, running to cancel_requested and is observed between processing stages. Existing cached evidence is retained. There is no deletion on viewer abort. Hard interrupt inside an upstream read may wait for timeout.

Backups: deploy/backup.sh absolute-directory uses pg_dump plus artifact tar and SHA-256 sums. Quiesce writes for a consistent DB/files snapshot, then copy to independent off-server storage. Restore into a separate empty Compose project: pg_restore database.dump and extract artifacts into its data volume; verify counts/checksums/report links before cutover. This restore procedure is not yet rehearsed; do not call it tested. Rollback application image with compatible schema and restored snapshot when migrations are not reversible.

Logging uses worker exceptions and Gunicorn access/error logs. /health/ checks DB. Full metrics/heartbeat/readiness/disk alerts are unfinished. No automatic cache eviction or scheduled updates run; saved report sequences use protected FKs. Avoid deleting data/ or local.sqlite3. Storage quota, orphan cleanup, refreshed-product provenance and incremental ingestion remain required.

Measured local limits: evidence/performance.json records eight repeated processing passes over the 4,176,000-byte real fixture in 0.273 s wall / 0.266 s CPU and 154,112,000-byte peak Windows process working set. Cached durable job return measured 0.039 s. Real sequence processing runs recorded 21.899 s (8 SPHEREx frames, 33,235,200 total input FITS bytes) and 8.714 s (4 native NEOSSat frames, 1,704,960 input bytes), with some download-cache hits. Historical metric `download_bytes` counted total input bytes, not network transfer; new jobs separate input_fits_bytes and network_download_bytes. These are local bounded observations, not a cold-network benchmark, browser-memory measurement or visitor-capacity claim.
